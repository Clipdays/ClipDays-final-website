# ClipDays website

Final responsive marketing website for ClipDays, built with React and Vinext for OpenAI Sites.

## Highlights

- Brand-guideline color palette and typography hierarchy
- Responsive desktop and mobile navigation
- Guest journey, value, capture stack, venues, partners and team sections
- Supplied photography, portraits, partner logos and optimized local assets
- Accessible headings, labels, focus states and reduced-motion support
- Contact form that prepares an email to `hello@clipdays.com`

## Development

Requirements: Node.js 22.13 or later.

```bash
npm ci
npm run dev
```

Use `npm run build` for a production build.

## Main files

- `app/page.tsx`: page content and interactions
- `app/globals.css`: responsive visual system
- `app/layout.tsx`: metadata and document structure
- `public/assets/`: optimized brand and photography assets
